# Hangman 1v1 — web

🎮 **Play:** <https://kharwtom.github.io/hangman-web/>

แข่งทายคำ 1 ต่อ 1 แบบเรียลไทม์ ปั่นเพื่อนด้วยสกิลและไอเทม ในธีมภาพวาดยุคเรเนซองส์ —
a real-time 1-vs-1 hangman duel with sabotage skills, 3D characters that
punch, hang and cheer, and Renaissance oil-painting art. No sign-up: pick a
nickname, create a room or join by a 4-letter code, or hit random match.

This repository holds the published web build of the private source
repository [kharwtom/hangman](https://github.com/kharwtom/hangman) plus the
public [privacy policy](privacy-policy.html) and [terms](terms.html), served
by GitHub Pages. Do not edit the app files here; they are replaced on every
deploy. The two policy pages are maintained by hand.
